# Teacher Carol 🇺🇸

Site oficial da Teacher Carol — aulas particulares de inglês.

## 🌎 Sobre

A Teacher Carol oferece aulas particulares de inglês com acompanhamento personalizado, focadas nas necessidades e objetivos de cada aluno.

## ✨ Recursos

- Apresentação da professora
- Informações sobre as aulas
- Benefícios do acompanhamento individual
- Área de contato
- Design responsivo para celular e computador

## 🚀 Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS

## 📚 Projeto

Desenvolvido para apresentar o trabalho da Teacher Carol de forma profissional e facilitar o contato com novos
